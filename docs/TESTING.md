# Как потестить Vice Code 1.2

Как попробовать мод из этой папки, не трогая свой Claude Code, пока сам не решишь его подключить. Все команды запускаются из папки проекта.

С 1.2 у мода два режима. **Lite** (по умолчанию) — только оформление: цвета приложения и город из символов за разговором, плюс одна карточка-приветствие. **Full** — игра 1.1 поверх того же оформления: розыск, строка над полем ввода, оружие, статистика. Переключение — `/vice full` и `/vice lite`.

Проверено перед выпуском 1.2.0:

- `claude plugin validate --strict .` проходит на Claude Code 2.1.319 (терминал) и 2.1.325 (движок десктоп-приложения). На 2.1.325 проходит и `--profile directory --strict`, проверка для каталога плагинов.
- `claude plugin test .` даёт 59 из 59 на обеих версиях. Тесты покрывают:
  - Lite: оформление и одна карточка без игры; карточку один раз там, где фон рисуется, и баннер в начале каждого разговора в терминале; продолженный разговор без карточки; окно, которое подключилось позже (`session.attach`); кнопку «Turn on the game»; `/vice full` и `/vice lite`; выбор, который держится между сессиями, и настройку, изменённую после выбора; `/vice paper`; `/vice off` и `/vice on`, в том числе в следующей сессии; движок без цветов (ему уходит только сцена); язык прошлой сессии; цвета для двух режимов или одного;
  - игру: приветственную карточку в ленте на всех поверхностях, строку над полем ввода, режимы `hud`, фон и `/vice backdrop`, огни и вертолёт по уровню розыска;
  - звёзды розыска, мигание огней, арест в ленте и строкой над полем ввода, выход, скрытый лимит, побег, работу в кредит, аптечки;
  - запуски без человека (мод ничего не делает, оформления тоже нет), слишком старую версию движка, общую полосу с другими модами;
  - импорт истории, автоязык, разбор логов, синтез звуков, память розыска между сессиями.
- `sh tools/ip-check.sh` не находит в репозитории названий игры и студии.

Чего тесты не показывают: как это выглядит в живом окне. Тестовый движок проверяет, что дерево элементов верное, но не пиксели. Список вопросов к первому живому запуску — в [DESIGN.md](DESIGN.md), раздел 7.

## Шаг 0. Посмотреть макеты без установки (1 минута)

Страница с макетами обоих режимов: окно десктопа до и после установки, Lite в тёмном и светлом окне с карточкой-приветствием, игра, терминал, панель и шаги установки, на русском и английском. Картинки и данные — те же, что у мода; слова в окнах и цвета панелей расставляет сама страница, поэтому это макет, а не снимок экрана.

```bash
npx -y esbuild@0.24.0 tools/preview.ts --bundle --platform=node --format=esm --outfile=preview/out/preview.mjs && node preview/out/preview.mjs
```

```bash
open preview/out/index.html
```

Так страница собирается по твоей настоящей истории (первый раз около минуты). С выдуманными цифрами, чтобы показать кому-то ещё:

```bash
node preview/out/preview.mjs --demo && open preview/out/mocks.html
```

В `preview/out/index.html` лежат твои цифры и названия проектов, поэтому папка `preview/out/` в `.gitignore`.

## Шаг 1. Терминал, без изменения настроек

Самый безопасный вариант: мод загружается только в эту одну сессию.

```bash
claude --plugin-dir .
```

**Сначала Lite.** Терминал не рисует ни цвета, ни фон, поэтому Lite тут — небольшая карточка в начале разговора: пиксельный город (если окно шире 64 колонок), «Welcome to Miami», строка про то, что цвета и город видны в десктопе, и подсказка с командами. Строки над полем ввода нет, спиннер и строки инструментов обычные, тостов нет. Проверь:

1. Карточка стоит в начале нового разговора и уезжает вверх вместе с ним.
2. `/vice` без слов показывает список команд Lite. `/vice wanted` отвечает, что это часть игры.
3. `/clear` — в новом разговоре карточка снова есть. `claude --continue` — карточки нет.

**Потом игра:** `/vice full`. Один раз после установки приходит тост с легендой (что значат звёзды, броня и здоровье), карточка игры встаёт в конец разговора, начинается импорт истории.

1. **Карточка.** Пиксельный закат, приветствие, 4 цифры за неделю, строка с отсчётом (или с розыском от ★★★), совет и команды.
2. **Импорт.** Через пару секунд «Поднимаю архив: N из M», в конце тост «Архив поднят: N миссий с …». Первый импорт идёт около минуты в фоне, дальше читаются только новые сессии.
3. **Строка над полем ввода.** Звёзды и время сброса, здоровье (контекст до автосжатия), броня (остаток недельного лимита), деньги. Цвета берутся из темы терминала: проверь и светлую тему (`/theme`).
4. **Подпись у поля ввода.** Если пятичасовой лимит занят на 40% и больше, рядом с режимом сессии видно `★★☆☆☆ · сброс через …`.
5. **Спиннер.** Вместо стандартных слов фразы вроде «Планирую ограбление». От ★★★★ — фразы погони.
6. **Оружие.** У каждого вызова инструмента метка: ДРОБОВИК у Bash, ПИСТОЛЕТ у Edit, БИНОКЛЬ у Read, РАЦИЯ у MCP.
7. **`/vice`.** Открывает панель статистики. Цифры 1–5 переключают вкладки: Общее, Досье, Арсенал, Тачки, Районы. Если фокуса нет — ctrl+x tab.
8. **`/vice wanted`** сразу открывает досье. **`/vice card`** ставит карточку ещё раз. **`/vice tip`** — следующий совет.
9. **`/vice radio`.** Синтвейв-луп «Neon Drive»; мод синтезирует его сам при первом включении (секунда-две). Работает и в Lite. В терминале играет только на macOS.
10. **`/compact`.** Тост «Аптечка: 180 тыс. → 42 тыс. токенов», в досье +1 аптечка.
11. **`/clear`.** В новом разговоре снова карточка, тосты о розыске не повторяются.
12. **Тишина.** Реплика «с улицы» не чаще раза в 20 минут. `claude -p "…"` с модом не показывает и не считает ничего.

**Переключение и выключение.**

- `/vice lite` — строка над полем ввода, оружие и спиннер пропадают сразу. Открой новую сессию: режим запомнился, там тоже Lite. То же с `/vice full`.
- Выбор держится, пока ты не поменяешь в `/config` настройку с тем же именем (`mode`, `paper`, `backdrop`). Поменял после выбора — побеждает настройка.
- `/vice off` — мод молчит в этой сессии и в следующих, `/vice` отвечает, что он выключен. `/vice on` возвращает.

## Шаг 2. Десктоп-приложение

Приложению нужно знать про мод, поэтому здесь придётся изменить настройки. Есть два способа, выбери один.

**Способ А, через локальный маркетплейс.** Изменения в папке подхватываются командой `/reload-plugins`, переустанавливать не нужно.

```bash
claude plugin install vice-code --marketplace "$PWD"
```

После этого открой новую сессию во вкладке Code. Откатить:

```bash
claude plugin uninstall vice-code
```

```bash
claude plugin marketplace remove vice-code
```

**Способ Б, через переменную окружения.** Добавь в `~/.claude/settings.json` блок с путём к папке проекта:

```json
{ "env": { "CLAUDE_CODE_PLUGIN_DIRS": "/полный/путь/к/vice-code" } }
```

Перезапусти приложение. Откатить: удалить эту строку.

**Что смотреть в Lite:**

1. **Цвета.** Окно становится фиолетовым, акцент розовый, предупреждения оранжевые. Проверь в тёмной теме приложения и в светлой: у каждой своя версия. Текст должен читаться и на панелях, и поверх фона.
2. **Город.** За разговором стоит город из символов: небо из знаков светлеет к горизонту, солнце в жалюзи справа, пальмы и дома по краям, под колонкой с текстом тихо. Картинка по местному часу: рассвет, день, закат, ночь. Движение шагами: жалюзи, пальмы, вода, лодка, птицы, облака, волна света по небу. Если в системе включено «Уменьшить движение», сцена стоит.
3. **Бумага.** В тёмном окне сцена на тёмной бумаге, в светлом на светлой. Если не совпало — `/vice paper dark` или `/vice paper light`, вернуть — `/vice paper auto`. Запиши, совпало ли само.
4. **Карточка-приветствие.** Одна, сразу после установки (в следующих сессиях её нет; `/vice card` покажет ещё раз). Наведи курсор на небо в баннере карточки: знаки под ним должны загораться. Кнопка «Turn on the game» включает игру.
5. **Курсор над фоном.** Проведи курсором по небу за разговором. Загорается или нет — зависит от приложения; запиши, что увидел.
6. **Узкое окно.** Сузь окно: две стороны сцены шагами сдвигаются к середине.
7. **`/vice backdrop`** — город пропадает, цвета остаются. Ещё раз — город вернулся.
8. **`/vice off`** — цвета и город уходят. `/vice on` — возвращаются.

**Потом Full (`/vice full`):**

1. **Карточка в ленте.** Родной текст приложения прямо на фоне: приветствие, цифры недели, совет, кнопки. Баннер со сценой у карточки только там, где фона нет.
2. **Строка над полем ввода.** Звёзды, две короткие шкалы, деньги. Проверь светлую и тёмную тему.
3. **Три звезды и больше.** У берега загораются патрульные огни; с четырёх по берегу едет машина и над городом висит вертолёт с прожектором; на пяти и при аресте вертолётов два. Звёзды в строке мигают около 13 секунд и замирают.
4. **Спиннер.** Если приложение пишет, что сейчас делает («Creating notes.md»), мод это оставляет. Фразы появляются, когда там просто «Working».

## Как проверить розыск, не сжигая лимит

- **Макеты** (шаг 0) показывают три звезды и арест на подставных цифрах.
- **Тесты** гоняют весь путь: от 40% до ареста, выход по таймеру, выход по ответу, побег, работу в кредит, огни и вертолёт в фоне:

```bash
claude plugin test .
```

- **Живьём** звёзды появятся сами, когда пятичасовой лимит перевалит за 40% (только в Full). Текущий процент видно в `/usage`. Звуки по умолчанию выключены; включаются в `/config` → vice-code → «Sound effects».

## Что делать, если что-то не так

- Запусти с логом: `claude --debug --plugin-dir .`. Если хук упал, в логе будет строка, которая начинается с `vice-code:`. Приложи её к issue на github.com/RebSem/vice-code.
- Мод нельзя сломать так, чтобы Claude Code перестал работать: упавший хук движок пропускает, и всё идёт как без мода.
- Ничего не видно? Проверь, не выключен ли мод (`/vice` ответит). Проверь версию: нужна 2.1.319 или новее.
- Цвета не пришли, а город есть — либо движок старше цветов, либо в `/config` выключено «App colors».
- Любую часть можно выключить в `/config`, раздел vice-code: цвета, город, строку над полем ввода, розыск, метки оружия, спиннер, тосты, деньги, импорт истории, звуки.

## Известные ограничения

- Цвета и город рисуют только десктопное и мобильное приложения. Терминал и VS Code остаются в своих цветах.
- Ничего из этого не проверено в живом окне тестами: они смотрят на дерево элементов, а не на пиксели. Доходит ли курсор до фона за разговором, решает приложение (баннер карточки — строка ленты, на нём наведение работает). Сцена выбирает светлую или тёмную бумагу по `prefers-color-scheme` внутри своей рамки; если не совпало с окном, лечится `/vice paper dark` или `/vice paper light`.
- Тема у сессии одна: оформление Vice Code заменит оформление другого мода и наоборот. Побеждает тот, кто поставил последним.
- Нужен Claude Code 2.1.319 или новее. На более старом мод покажет одну строку с просьбой обновиться.
- Движок не сообщает о сбросе окна лимита. Мод ставит свой будильник на время сброса, поэтому карточка ареста сжимается через несколько секунд после сброса, а не мгновенно.
- Лимит, которого нет в цифрах (например, недельный лимит отдельной модели), мод видит только по отказу. Время выхода для него неизвестно, и карточка так и пишет.
- В VS Code и в мобильном приложении нет полосы над полем ввода: там видны карточки в ленте, панель и тосты.
- Стоимость старых сессий есть не во всех логах. Где её нет, строка помечена звёздочкой.
- Импорт использует `awk` (есть на macOS и Linux). На Windows без `awk` прочитаются только логи до 4 МБ.
- В терминале звук играет только на macOS. На Linux и Windows радио скажет, что проигрывателя нет.
